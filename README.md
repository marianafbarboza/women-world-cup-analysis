# ⚽ Women's World Cup Analysis (2019 vs 2023)

This project explores whether women's football has become more offensive by analyzing match data from the FIFA Women’s World Cup 2019 and 2023, using publicly available StatsBomb datasets.

---

## 🎯 Objective

The goal of this analysis is to evaluate offensive patterns and match dynamics between the two tournaments, focusing on:

- Average goals per match;
- Frequency of high-scoring games (4+ goals);  
- Match competitiveness (goal difference);
- Proportion of draws;  
- Distribution of match results.  

---

## 📊 Key Insights

- The average number of goals per match **decreased** from 2019 to 2023;  
- However, the proportion of **high-scoring games increased significantly**;  
- The average goal difference remained **relatively stable**; 
- The percentage of **draws increased substantially**, suggesting higher competitiveness;  
- Match results in 2023 show **greater variability**, with both balanced and high-margin games.  

👉 Overall, the findings suggest that the game is becoming more **unpredictable**, rather than simply more or less offensive.
